## Прототип: завод смазочных материалов (версия 1.1)

Прототип и 3D-тур показывают один и тот же завод: 7 этапов от приёмки сырья до отгрузки, партия 25 т,
узкое место — лаборатория ОТК. План 115 т/сут, обещанный срок — 48 ч от запуска до отгрузки.

| Сценарий | Цикл, ч | Выпуск, т/сут | В срок, % | Стоимость, ₽/т |
|---|---|---|---|---|
| AS-IS | 41,7 | 114 | 81 | 5 427 |
| A · экспресс-анализ проб | 34,5 | 115 | 99 | 5 171 |
| B · быстрая переналадка (SMED) | 40,5 | 114 | 88 | 5 378 |
| **C · A + B** | **34,1** | **114** | **99** | **5 098** |

Лучший сценарий выбирается по правилу FR-11: меньше цикл, при равном цикле — дешевле; сценарии с отставанием
от плана больше 3 % не участвуют. Вывод: переналадка сама по себе не помогает, ограничение — в мощности ОТК.
Если в «Оборудовании» включить второй пост анализа, узкое место уходит из лаборатории.

**Связка с 3D-туром.** Раздел «3D-тур» показывает настоящий тур (ветка `3d`) во фрейме и после каждого прогона
передаёт в него цикл, выпуск, загрузку и длительность каждого этапа: тур показывает эти цифры на сцене и переносит
узкое место. Кнопка «Показать в 3D-туре» у узкого места открывает его локацию прямо во фрейме.
Адрес тура: `?tour=…` в ссылке, иначе `http://localhost:8080/` (сборка в Docker), иначе `http://localhost:5173/`
(сервер разработки). Если тур не запущен, показывается изометрическая схема.

## Как пользоваться

1. **Документ** — открыть `.docx` в Word или готовый `docs/ТЗ…pdf`. Рисунки вставлены на альбомных
   страницах, чтобы подписи читались.
2. **Презентация** — открыть `.pptx` в PowerPoint или LibreOffice Impress, режим докладчика:
   к каждому из 12 слайдов написаны заметки (что говорить и какие цифры называть).
3. **Прототип** — открыть `prototype/index.html` в браузере. Двигать ползунки, нажимать «Пересчитать модель»,
   кликать по меткам на сцене. Вместе с 3D-туром: запустить тур (ветка `3d`:
   `docker compose -f docker-compose.3d.yml --profile prod up tour` или `npm --prefix frontend run dev`),
   затем открыть прототип — раздел «3D-тур» сам переключится на тур. Через локальный сервер:
   `python -m http.server 5500 --directory prototype` → http://localhost:5500.
4. **Пересчитать данные** — `node scripts/gen_demo_data.js` (обновит `data/demo-data.json`),
   `node scripts/run-sim.js` (таблица сценариев → `scripts/metrics.json`).
5. **Проверить прототип** — `node scripts/test_prototype.js` (headless-прогон `app.js`, без браузера).
6. **Пересобрать презентацию** — `python scripts/build_deck.py` (берёт `figures/*.png`, кладёт `.pptx` в корень).

## Логотип в прототипе

В левом верхнем углу боковой панели стоит место под логотип. Положите файл по пути:

```
prototype/assets/logo.png
```

Сейчас там лежит `logo.png`. Подойдёт и SVG или другой PNG с прозрачным фоном, высота 100–200 px, соотношение
примерно 4:1 — панель тёмно-синяя, поэтому логотип должен быть светлым. Если файла нет,
показывается пунктирная заглушка «ЛОГОТИП» с этим же путём. Для `.svg` поправьте `src`
у `#brand-logo` в `prototype/index.html`. Подробности — в `prototype/assets/README.txt`.

## Ограничения пакета

- Все данные синтетические: доступ к ERP/MES/1С по условиям задания отсутствует.
- 3D-тур — отдельное приложение (ветка `3d`, Three.js); без него прототип показывает изометрическую схему на Canvas.
- PDF собран из текущей версии документа; если правите `.docx`, переэкспортируйте `docs/…pdf`.
