ЦИФРОВОЙ ДВОЙНИК ЗАВОДА И 3D-ТУР — ВЕРСИЯ ДЛЯ ПОКАЗА
=====================================================

Как запустить (Windows 10/11)
-----------------------------
1. Распакуйте архив в любую папку (не запускайте прямо из архива).
2. Дважды щёлкните ZAPUSK.bat.
3. Откроется браузер с прототипом цифрового двойника. Раздел «3D-тур» внизу страницы
   показывает тур по тому же заводу. Окно с чёрным фоном не закрывайте, пока идёт показ.

Если Windows спросит про доступ к сети — можно отказать: сервер работает только на этом компьютере.
Если ZAPUSK.bat не запускается (политика компании) — правой кнопкой по serve.ps1 →
«Выполнить с помощью PowerShell».

Адреса (порт может быть 8765–8785, точный — в чёрном окне)
-----------------------------------------------------------
  http://localhost:8765/twin/   — цифровой двойник: метрики, загрузка этапов, сценарии, 3D-тур во фрейме
  http://localhost:8765/        — 3D-тур отдельно: маршруты, вход, дашборд руководителя

Демо-входы в туре (пароль у всех demo1234)
------------------------------------------
  manager@demo.ru  — руководитель: дашборд
  editor@demo.ru   — редактор: расстановка точек кликом по сцене
  admin@demo.ru    — администратор

Что показать за 5 минут
-----------------------
1. Двойник: 4 метрики, загрузка этапов, узкое место — лаборатория ОТК (95 %).
2. «Оборудование» → включить «Пост анализа ОТК №2»: цикл падает, узкое место уходит.
3. «Показать в 3D-туре» у узкого места — тур открывает лабораторию с очередью проб.
4. Тур отдельно: маршрут «Мощности и эффективность» → «Далее» по шагам → карточка точки → «Процесс» / «Кейс».
5. Вход manager@demo.ru → «Дашборд» → «Показать в туре».

Без Windows
-----------
macOS / Linux: в папке site выполните  python3 -m http.server 8765  и откройте http://localhost:8765/twin/
(обновление страницы на адресах вида /tour может дать 404 — открывайте ссылки из интерфейса).

Все данные синтетические.
